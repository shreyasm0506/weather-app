# Weather App 🌤️

A Python command-line application that fetches real-time weather data 
for any city in the world using the OpenWeatherMap API.

## Features
- Real-time temperature and feels like
- Humidity and wind speed
- Weather conditions
- Handles invalid city names gracefully

## Technologies Used
- Python
- Requests library
- OpenWeatherMap API
- JSON parsing

## How to Run
1. Clone this repository
2. Install dependencies:
   pip install requests
3. Get a free API key from openweathermap.org
4. Replace YOUR_API_KEY in the code with your key
5. Run:
   python weather_app.py
